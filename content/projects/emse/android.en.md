## Context

During my final year at Mines de Saint-Étienne, a web development course had us work on building a mobile application. In pairs, we chose to build an app for visualizing speed camera locations.

## Building an API

To let our application access speed camera data, we had to build a RESTful API. This API was responsible for managing the camera data, including adding, removing, and updating entries. We used the NestJS framework for this, and gathered public data to populate the API.

## Android interface

In parallel, an Android interface was built using Kotlin in the Android Studio IDE. This interface let users interact with the app through various menus, including a scrollable list of speed cameras with accessible details, as well as a map showing their geographic distribution.
